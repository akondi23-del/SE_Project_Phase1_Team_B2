Project Details

Problem statement:Traditional banking systems often suffer from long waiting lines, poor time management, and lack of guidance for customers. Many users are unsure which service or department they need, which increases confusion and delays.

Proposal solution:QueueBank MS is a smart appointment-based system that allows customers to book bank visits online and includes an AI-powered chatbot assistant. The chatbot helps users identify the correct service, provides guidance, and improves the overall booking experience.

Project Scope

Aim:
To develop a smart queue management system that improves banking efficiency and enhances customer experience.
Objectives:
•	Reduce waiting time in banks
•	Provide online appointment booking
•	Improve staff workflow and service efficiency
•	Help users choose the correct service using AI
•	Enhance user experience through smart assistance

Application Description
Queue Bank MS is a web-based application designed for three types of users:
•	Customers (Users): Book and manage appointments
•	Staff: Handle daily appointments and update status
•	Admin: Manage users, staff, services, and system data
Additionally, the system integrates an AI chatbot assistant that helps users interact with the system more easily.


Key Features:
•  Online appointment booking
•  Real-time queue management
•  Admin dashboard with system control
•  Staff dashboard for managing bookings
•  AI chatbot to guide users to the correct service/department
•  Modern and responsive UI

AI Chatbot Feature
The system includes an AI chatbot that assists users by:
•	Answering common questions
•	Helping users choose the correct banking service
•	Guiding users through the booking process
•	Reducing confusion and improving user experience
This feature makes the system smarter and more user-friendly compared to traditional queue systems.
